Email Briefing v1.1.17

Window and layout fixes.

## Fullscreen and maximize now work

Both had been greyed out on Windows since the first release. The window was created with `titleBarStyle: 'hiddenInset'` — a macOS-only value. On Windows the valid values are `'default'` and `'hidden'`, and the custom title bar requires `'hidden'`, so the window never received proper maximize/fullscreen styles.

- Platform-aware title bar, with the caption-button overlay applied only where it is supported
- Explicit `resizable`, `maximizable` and `fullscreenable` window options
- **F11** and **Alt+Enter** toggle fullscreen (the app hides its menu bar, so it could not rely on the default menu's accelerator)
- Window capabilities are logged at startup for diagnostics

## Layout

- The header now sits below the title-bar strip, so the Home / History / Aa / settings controls stay flush right — aligned with the topic grid — while remaining clear of the minimize, maximize and close buttons. The strip is draggable, and collapses in fullscreen to reclaim the space.
- Screens that centre themselves (idle, loading, error) sat about 49px below the window's centre, because the header pushed the content region down with nothing balancing it. They are now measured at runtime and centred properly, re-adapting on fullscreen toggle and when the font-size setting changes the header height.
- The scrollbar on long screens no longer pulls the topic grid and Quick Bits a few pixels left of centre, and content no longer shifts between screens.
